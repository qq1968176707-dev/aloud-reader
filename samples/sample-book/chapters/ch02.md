# 第二章 · 图片与排版

图书包里的 `images/` 目录放图片，章节用普通的 Markdown 语法引用它们。导入时，程序会把图片复制进书的私有目录，并把 `src` 改写成 `aloud://book/<书号>/images/...`——正文里不会留下任何指向外网的地址。

![示意图：一行文字被点亮，其余部分暗下去，声音与高亮同步推进](../images/diagram-readalong.svg)

上面这张图的说明文字来自 Markdown 的 alt 文本，导入时会自动变成 `<figcaption>`。点击图片可以放大查看，按 Esc 关闭。

## 排版是可以让步的

正文的字体、字号、行距、页边距、亮度全都可调。默认给的是一套克制的值：

| 项目 | 默认值 | 可调范围 |
| --- | --- | --- |
| 字号 | 19px | 13–34px |
| 行距 | 1.75 | 1.30–2.40 |
| 页边距 | 12% | 0–34% |
| 亮度 | 100% | 30–100% |

窗口够宽的时候，分页模式会自动变成左右两栏，像摊开的一本书；窗口窄了又自动收回单栏。这条规则可以在「外观」面板里改成固定单页或固定双页。
